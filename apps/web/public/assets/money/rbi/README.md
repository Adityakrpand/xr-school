# RBI currency reference images

These reduced-resolution, one-sided educational reference images were obtained from the Reserve Bank of India website for the Class 1 currency-recognition simulation.

- Banknote source pattern: `https://rbi.org.in/cw/images/Rs{value}/{value}-note-front.png`
- Coin source page: `https://rbi.org.in/Scripts/restrospectcoins.aspx`
- Retrieved: 15 September 2026

The simulation displays them at small scale for denomination recognition. It does not present them as printable currency, and the ₹500 fallback is an explicitly marked educational specimen based on RBI-published colour and denomination guidance.
